Gaussian-process Bayesian optimisation with expected improvement fits a smooth Matern model to the yields measured so far and scores every untried condition by how much it is expected to beat the current best. The kernel is a Matern-5/2 with a small noise term, the goal is to maximise yield, and each round takes the batch of conditions with the highest expected improvement. TabPFN is a transformer pretrained on synthetic tabular tasks that predicts in context, without a separate training step. The installed TabPFN package cannot download its model weights without a one-time license and API key, so this arm uses a random forest instead: each tree predicts the yield, and the next batch is the conditions with the highest 90th-percentile prediction. The transfer arm uses that same 90th-percentile rule after adding yields from other substrates when that history is available, and otherwise uses only the current task. Equal scores are broken at random.
